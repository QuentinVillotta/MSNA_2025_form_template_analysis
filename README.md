# MSNA 2025 Form Template Analysis

Interactive analysis of MSNA 2025 country surveys compliance with template and Indicator Bank.

## Quick Access

**Interactive Notebooks**: [http://impact-msna-analysis-2025.switzerlandnorth.azurecontainer.io:2718](http://impact-msna-analysis-2025.switzerlandnorth.azurecontainer.io:2718)

**Static Reports**: [GitHub Pages](https://impact-initiatives.github.io/MSNA_2025_form_template_analysis/)

## Available Analyses

1. **Template vs IB Compliance**: Compare template columns against Indicator Bank indicators
2. **Country Compliance**: Analyze 14 MSNA country surveys against template structure

## For Developers

- **Local Setup**: `docker compose up --build` → http://localhost:2718
- **Deployment**: See [DEPLOYMENT.md](DEPLOYMENT.md)
- **Source**: Notebooks in `notebooks/`, data in `data/`
